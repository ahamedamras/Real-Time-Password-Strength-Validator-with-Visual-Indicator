# Real-Time-Password-Strength-Validator-with-Visual-Indicator
Project Description

The Password Strength Checker is a simple and interactive web application developed using HTML, CSS, and JavaScript. It helps users create stronger passwords by checking their password strength in real time. The application evaluates passwords based on length, uppercase letters, numbers, and special symbols. It displays a visual strength indicator with different colours and provides feedback to improve password security.

How It Works

Enter Password: Users type a password into the input field.

Password Validation: The system automatically checks four conditions: at least 8 characters, an uppercase letter, a number, and a special symbol.

Strength Calculation: JavaScript calculates a score based on how many conditions are satisfied.

Strength Indicator: A coloured progress bar displays the password strength:

Weak: Red (25%)

Medium: Orange (50%)

Strong: Light Green (75%)

Very Strong: Green (100%)

Requirement Feedback: The requirements change to green when the password meets each condition.

Show/Hide Password: Users can click the Show or Hide option to control password visibility.

Technologies Used

HTML: Creates the password input field, strength indicator, and validation requirements.

CSS: Provides the responsive layout, modern card design, and progress bar styling.

JavaScript: Validates the password, calculates its strength, updates the progress bar, and controls password visibility.

Conclusion

This project demonstrates real-time password validation using JavaScript. It provides instant visual feedback and encourages users to create stronger passwords through a simple, responsive interface.
